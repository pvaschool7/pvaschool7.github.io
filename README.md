# pvaschool7.github.io
Сайт-портфолио учителя. Структура: index.html, style.css, materials/*.html, data/ (файлы для скачивания).
Загрузка: залить содержимое папки в корень репозитория pvaschool7.github.io (ветка main), Settings → Pages → Deploy from branch → main / root.
Новый материал: положить файл в data/, скопировать materials/uslovnaya-veroyatnost.html, поправить текст и ссылку, добавить карточку в index.html.
Меню: боковое, одинаковый блок <aside class="side"> есть в каждой странице (index, informatika, matematika, kontakty, materials/*). При добавлении раздела правьте его во всех файлах.
Подразделы «Ученикам» и «Учителям» — это якоря #uchenikam и #uchitelyam на страницах informatika.html и matematika.html.
Новый материал: положить файл в data/, скопировать materials/uslovnaya-veroyatnost.html, добавить карточку на index.html и в нужный раздел (matematika.html / informatika.html).
Страница «Обо мне»: obo-mne.html (ссылка с блока «Об учителе» на главной; в боковое меню не добавлена).
