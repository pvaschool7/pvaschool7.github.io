# pvaschool7.github.io
Сайт-портфолио учителя. Структура: index.html, style.css, materials/*.html, data/ (файлы для скачивания).
Загрузка: залить содержимое папки в корень репозитория pvaschool7.github.io (ветка main), Settings → Pages → Deploy from branch → main / root.
Новый материал: положить файл в data/, скопировать materials/uslovnaya-veroyatnost.html, поправить текст и ссылку, добавить карточку в index.html.
Меню: боковое, одинаковый блок <aside class="side"> есть в каждой странице (index, informatika, matematika, kontakty, materials/*). При добавлении раздела правьте его во всех файлах.
Подразделы «Ученикам», «Учителям» и «Если ты пропустил урок» — отдельные страницы: matematika-uchenikam.html, matematika-uchitelyam.html, matematika-propushel-urok.html, informatika-uchenikam.html, informatika-uchitelyam.html, informatika-propushel-urok.html. Страницы «Если ты пропустил урок» (informatika-propushel-urok.html, matematika-propushel-urok.html) имеют ту же структуру, что и «Ученикам» (классы 7–11, в информатике — подразделы по темам), и заполняются записями уроков: дата, что прошли, задания и материалы. На вводных страницах и в боковом меню у каждого предмета три подраздела. Название сайта на главной: «Информатика и Математика» (Информатика — первой). Страницы matematika.html и informatika.html — вводные, с двумя ссылками. На каждой из шести страниц с материалами (ученикам / учителям / пропустил урок — по информатике и математике) материалы разбиты по классам 7–11: сверху — закреплённое верхнее меню-табы (.grade-bar → .grade-tab «N класс»); клик по табу показывает панель класса (<section class="grade-panel" id="k7"…"k11">) и скрывает остальные, выбранный класс пишется в адрес (#k7…#k11). Без JavaScript видны все панели подряд. В «Информатике» внутри класса — раскрывающиеся подразделы по темам программы (<details class="subsec">): 7 кл. — Цифровая грамотность, Теоретические основы информатики, Информационные технологии; 8 кл. — Теоретические основы информатики, Алгоритмы и программирование; 9 кл. — Цифровая грамотность, Теоретические основы информатики, Алгоритмы и программирование, Информационные технологии; 10 и 11 кл. — Базовое изучение предмета, Углубленное изучение предмета. Новый материал: карточка в <div class="cards"> нужного подраздела (информатика) или нужного класса (математика). Пример внешней карточки-файла: <a class="card" href="https://disk.yandex.ru/i/…" target="_blank" rel="noopener"> с тегами класса и раздела (презентации 7 класса, раздел «Теоретические основы информатики»). Подразделы свёрнуты по умолчанию; чтобы подраздел был раскрыт сразу, добавьте атрибут open к соответствующему <details>.
Интерактивные уроки (7 класс, информатика): lessons/izmerenie-informacii.html и lessons/informacionnye-processy.html — самостоятельные страницы к одноимённым презентациям (стили подключают ../style.css, свои — внутри <style>). Работа в паре: имена на табло, переключатель «Ученик А / Ученик Б»; в заданиях роли фиксированы (А решает 1–3, Б — 4–5), вердикты поднимает выбранный на табло ученик. Автопроверка ответов: +1 с первой попытки (вторая попытка — подсказка, третья — разбор), вердикты +1, доказательства/ловушка/запрос/письменный финал — баллы «на проверке» (+2/+2/до +4/до +8). Прогресс сохраняется в localStorage (ключи pva-lesson-izmerenie / pva-lesson-processy), сброс — «Сбросить урок». В конце урока — итоговый балл пары и предварительные отметки («Показать результат учителю» — карточка для печати). Кнопки «Пройти урок в классе» стоят на карточках материалов 7 класса (informatika-uchenikam.html, informatika-uchitelyam.html) и на странице «Если ты пропустил урок».
Новый материал: положить файл в data/, скопировать materials/uslovnaya-veroyatnost.html, добавить карточку на index.html и в нужный раздел (matematika.html / informatika.html).
Страница «Обо мне»: obo-mne.html (ссылка с блока «Об учителе» на главной; в боковое меню не добавлена).
Иконка сайта: icon-pva.svg (основная), favicon.ico и apple-touch-icon.png (запасные). Подключены тегами <link rel="icon"> в <head> каждой страницы.
Иконка в левом верхнем углу: <img class="logo-ico"> внутри <a class="logo"> в блоке бокового меню каждой страницы.
Футер: <footer class="foot"> одинаковый в каждой странице (бренд, разделы, контакты, копирайт). При смене почты или разделов правьте во всех файлах.
Фотография: img/photo.jpg (720×900, без метаданных EXIF). Показана на obo-mne.html и в блоке «Об учителе» на index.html. Заменить фото — положить новый файл под тем же именем.
