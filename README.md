# pvaschool7.github.io
Сайт-портфолио учителя. Структура: index.html, style.css, materials/*.html, data/ (файлы для скачивания).
Загрузка: залить содержимое папки в корень репозитория pvaschool7.github.io (ветка main), Settings → Pages → Deploy from branch → main / root.
Новый материал: положить файл в data/, скопировать materials/uslovnaya-veroyatnost.html, поправить текст и ссылку, добавить карточку в index.html.
