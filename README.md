# pvaschool7.github.io
Сайт-портфолио учителя. Структура: index.html, style.css, materials/*.html, data/ (файлы для скачивания).
Загрузка: залить содержимое папки в корень репозитория pvaschool7.github.io (ветка main), Settings → Pages → Deploy from branch → main / root.
Новый материал: положить файл в data/, скопировать materials/uslovnaya-veroyatnost.html, поправить текст и ссылку, добавить карточку в index.html.
Меню: боковое, одинаковый блок <aside class="side"> есть в каждой странице (index, informatika, matematika, kontakty, materials/*). При добавлении раздела правьте его во всех файлах.
Подразделы «Ученикам», «Учителям» и «Если ты пропустил урок» — отдельные страницы: matematika-uchenikam.html, matematika-uchitelyam.html, matematika-propushel-urok.html, informatika-uchenikam.html, informatika-uchitelyam.html, informatika-propushel-urok.html. Страницы «Если ты пропустил урок» (informatika-propushel-urok.html, matematika-propushel-urok.html) имеют ту же структуру, что и «Ученикам» (классы 7–11, в информатике — подразделы по темам), и заполняются записями уроков: дата, что прошли, задания и материалы. На вводных страницах и в боковом меню у каждого предмета три подраздела. Название сайта на главной: «Информатика и Математика» (Информатика — первой). Страницы matematika.html и informatika.html — вводные, с двумя ссылками. На каждой из четырёх страниц материалы разбиты по классам: раскрывающиеся секции «7 класс»…«11 класс» (<details class="grade" id="k7"…"k11">, чип-навигация .grade-nav). Клик по заголовку класса (или по чипу «N класс») разворачивает/сворачивает секцию. В «Информатике» внутри класса — раскрывающиеся подразделы по темам программы (<details class="subsec">): 7 кл. — Цифровая грамотность, Теоретические основы информатики, Информационные технологии; 8 кл. — Теоретические основы информатики, Алгоритмы и программирование; 9 кл. — Цифровая грамотность, Теоретические основы информатики, Алгоритмы и программирование, Информационные технологии; 10 и 11 кл. — Базовое изучение предмета, Углубленное изучение предмета. Новый материал: карточка в <div class="cards"> нужного подраздела (информатика) или нужного класса (математика). Пример внешней карточки-файла: <a class="card" href="https://disk.yandex.ru/i/…" target="_blank" rel="noopener"> с тегами класса и раздела (презентации 7 класса, раздел «Теоретические основы информатики»). По умолчанию секции свёрнуты; чтобы класс или подраздел были раскрыты сразу, добавьте атрибут open к соответствующему <details>.
Новый материал: положить файл в data/, скопировать materials/uslovnaya-veroyatnost.html, добавить карточку на index.html и в нужный раздел (matematika.html / informatika.html).
Страница «Обо мне»: obo-mne.html (ссылка с блока «Об учителе» на главной; в боковое меню не добавлена).
Иконка сайта: icon-pva.svg (основная), favicon.ico и apple-touch-icon.png (запасные). Подключены тегами <link rel="icon"> в <head> каждой страницы.
Иконка в левом верхнем углу: <img class="logo-ico"> внутри <a class="logo"> в блоке бокового меню каждой страницы.
Футер: <footer class="foot"> одинаковый в каждой странице (бренд, разделы, контакты, копирайт). При смене почты или разделов правьте во всех файлах.
Фотография: img/photo.jpg (720×900, без метаданных EXIF). Показана на obo-mne.html и в блоке «Об учителе» на index.html. Заменить фото — положить новый файл под тем же именем.
